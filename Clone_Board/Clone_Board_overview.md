# Overview

## The Microcontroller

The dev board that I've decided to move foward with is the [NUCLEOL412RB](https://www.st.com/en/evaluation-tools/nucleo-l412rb-p.html). Although I wanted to keep the project as simple as possible, this dev board has a variety of peripherals that I believe would be good for me to learn, like ADCs, UART, I2C, SPI, etc.
